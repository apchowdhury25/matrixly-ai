What this week means

Counts come from live agent APIs when online, or from each agent’s local data folder (audit, tickets, bookings, invoices) for offline demos.

Business tool connections

Store connection labels for your team. Secrets should live in each agent’s .env on the server — never paste production passwords into the browser.

Security & privacy

  • Pack API key protects this dashboard (header X-API-Key).
  • Each agent has its own API/widget keys — rotate for production.
  • HITL gates block external sends, calendar writes, and accounting posts by default.
  • Audit logs are append-only JSONL per agent + pack-level events.
  • Prefer TLS reverse proxy (Caddy/nginx) and private network between containers.

Runtime URLs are set in agents/starter-pack/.env.
