DocForge

Draft professional proposals, quotes, contracts, and reports for SMBs — pull client data, apply approved templates, keep brand and pricing rules consistent, route for internal approval with version tracking, and export PDF or editable formats.

  • ▸ Crew: Intake · Legal · Drafter · Brand check
  • ▸ Templates + brand memory + pricing catalog
  • ▸ HITL approval · version history · MD/HTML/PDF export
FastAPI Templates HITL PDF export

1. Intake

CRM, forms, or manual brief with line items.

2. Draft

Template-driven proposals, quotes, contracts, reports.

3. Brand check

Pricing rules, placeholders, quality score.

4. Approve

HITL queue with version snapshots.

5. Export

PDF, HTML, Markdown, send status log.

Deploy on this machine

Code: agents/doc-forge · Guide: agents/doc-forge/README.md 

cd agents/doc-forge
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python scripts/smoke_test.py
python -m src.cli serve

Templates: drop Markdown into templates/. Brand: brand/guidelines.md.

Safety: Customer-facing documents require human approval before send by default.
